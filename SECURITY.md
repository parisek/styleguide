# Security policy

## Supported versions

Only the latest minor release of the current major version gets security fixes.

| Version | Supported |
|---------|-----------|
| 1.x (latest minor) | Yes |
| Older minors of 1.x | No |
| 0.x | No |

## Report a vulnerability

Do not open a public issue.

Use GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/parisek/styleguide/security).
2. Select "Report a vulnerability".

You can also go directly to
[the report form](https://github.com/parisek/styleguide/security/advisories/new).

We aim to reply within 7 days.

## What to include

- The affected version of `parisek/styleguide`.
- The steps to reproduce the problem.
- The impact: what an attacker can do.

## What happens next

We confirm the problem and prepare a fix.
The fix ships as a patch release.
We publish a GitHub Security Advisory with the release.
